# OLIVIA

OLIVIA 是一个在你自己电脑上运行的中文陪伴程序，在终端里用文字聊天。现在是内部测试版，还在打磨，会出错，也欢迎你告诉我们哪里不对。

## 它是什么，不是什么

- 它是一个可以说说话的地方：听你说，回应你，在合适的时候给一些小方法，以及当地的求助电话。
- 它不是心理咨询，不做诊断，也不提供治疗，不能代替医生、心理咨询师或你身边的人。
- 它只为 18 岁及以上的成年人设计，第一次使用时会请你确认年龄。
- 它运行时不联网。聊天内容不会上传，也不会写进任何文件。

## 如果你现在有危险

请马上联系当地的紧急服务，或者你信任的人，不要等这个程序。

- 中国大陆：110（报警）、120（急救）；心理援助热线 12356（各地接听时段不同，部分省份夜间不接听）
- 香港：999；18111 精神健康支援热线（24 小时）
- 其他地区：设置好地区后运行 `olivia resources` 查看当地电话，或访问 <https://findahelpline.com/>

## 安装

需要先装好 Python 3.11 或更新版本、git 和 [pipx](https://pipx.pypa.io/)。

安装 pipx（装完后重新打开终端）：

- macOS：`brew install pipx`，然后 `pipx ensurepath`
- Windows：`py -m pip install --user pipx`，然后 `py -m pipx ensurepath`
- Linux：用系统的包管理器安装（例如 `sudo apt install pipx`），然后 `pipx ensurepath`

然后安装 OLIVIA：

```bash
pipx install git+https://github.com/Olivia295/OLIVIA.git
olivia --version
```

如果电脑上默认的 Python 版本低于 3.11，可以指定版本：`pipx install --python python3.11 git+https://github.com/Olivia295/OLIVIA.git`。

## 更新与卸载

```bash
pipx reinstall olivia    # 从 GitHub 重新安装最新版本
pipx uninstall olivia    # 卸载程序
```

卸载不会删除你的本地设置，需要的话按下面「数据存在哪里」手动删除。

## 开始使用

| 命令 | 作用 |
| --- | --- |
| `olivia chat` | 开始聊天。第一次会先完成几步设置：确认你已满 18 岁、怎么称呼你、所在地区等。输入 `/exit` 结束。危机筛查除了规则，还会参考一个装在本机的小模型（不联网）。这个模型更敏感：只会让判断更谨慎，不会放松规则已经做出的判断，所以偶尔也会在普通的话上弹出求助卡片。模型文件缺失或校验不通过时自动只用规则，并在开始时说一句。设置打不开时（钥匙串锁住、钥匙丢失或文件损坏），会先显示求助电话，再说明原因和下一步 |
| `olivia region` | 查看保存的国家/地区；`olivia region HK` 修改（也认得 `china`、`中国`、`大陆`、`香港`、`台湾`、`澳门`、`美国`、`uk` 这类叫法），`olivia region --clear` 清除。支持的地区：CN、HK、MO、TW、US、CA、GB、AU；其他地方用 `olivia region ZZ`，时区默认取这台电脑的设置，也可以加 `--timezone Asia/Tokyo` 指定。有多个时区的地区（US、CA、AU）在电脑时区不属于该地区时需要加上时区，例如 `olivia region US --timezone America/New_York`。认不出的地区不会被保存 |
| `olivia persona` | 查看四种陪伴方式（温和包裹、沉静哲思、平视战友、静默树洞）和现在用的是哪一种；`olivia persona 2`、`olivia persona 沉静哲思`，或者用简称 `树洞`、`静默`、`哲思`、`禅`、`战友`、`理性`、`温和` 更换，下次聊天生效 |
| `olivia profile` | 查看或修改双方的称呼（你的称呼、OLIVIA 的称呼）和不想谈的话题。输入序号选一项再修改；新写的话题会替换原来的，输入 `0` 清空，直接回车不改。下次聊天生效 |
| `olivia health` | 查看或修改你愿意告诉 OLIVIA 的健康情况（以往被专业人士评估过的情况，以及心脏或呼吸方面的情况、家里是否安全），用来避开不适合你的练习。列表只显示中文名称。只在这台电脑上加密保存；电脑没有系统钥匙串时不会保存 |
| `olivia safety-plan` | 在平静的时候写一份自己的安全计划：预警信号、能让自己好受一点的方法、能让自己分心的人或地方、可以求助的人和电话、让环境更安全。每一部分都可以跳过，之后可以查看、修改或清空。求助的人可以把名字和电话写在同一行（例如「表姐 13800000000」），也可以分两步写；写得太长时会说明还没存下、怎么改，不会悄悄丢掉。只在这台电脑上加密保存；电脑没有系统钥匙串时不会保存。聊天中特别难熬的时候，OLIVIA 会把其中的安抚方法、分心去处和求助的人拿出来给你看 |
| `olivia journal` | 看看最近七天的小结：聊了几次、聊天前后的心情分、用 `[20%]` 这样的前缀说过电量时有几次电量很低（和上周的次数放在一起），以及试过的小练习。开头和结尾的语气跟你选的陪伴风格走，事实和数字不变。只根据本机的聊天小结生成，不含聊天原文；你说过不想谈的话题不会出现在里面。看完会问一句有没有帮助，可以直接回车跳过 |
| `olivia stats` | 看看使用数字：一共聊了几次、最近 7 天和 30 天各几次、深夜（00:00–05:00）聊天的占比、回复里聊到身边可以联系的人的占比、心情自评结束时比开始时平均变化多少、结束时心情分比开始时高的聊天占比，以及周记“有没有帮助”回答过几次、其中“有帮助”的占比。只有次数、比例和分数，不含任何聊天内容；只根据本机加密的聊天小结和周记记录计算，不另存任何东西。较早版本留下的小结没有深夜与轮数记录，只计入聊天次数和自评 |
| `olivia memory` | 查看 OLIVIA 在这台电脑上记得什么：每次聊天的小结、周记记录和你让它记住的话（按时间编号，日期和时间按你现在设置的时区显示），以及还存着哪些别的东西（只列名字，不显示健康信息和安全计划的内容；不想谈的话题只说有几个）。方法偏好按小练习的名字逐个列出，每个配一句话说明（例如“最近说过不适合，会少推荐一段时间”“说过有帮助，会多推荐一些”），不显示数字，序号供 `olivia forget --method` 使用。只显示在屏幕上，不会另存成文件 |
| `olivia memory --edit 2` | 修改第 2 条你让 OLIVIA 记住的话（序号见 `olivia memory`）：先显示现在的内容，再写新的，输入「确认」或「确定」后保存；原来的那段话会和删除一样被加密擦除。聊天小结和周记记录是程序按固定格式写的，不能修改，可以用 `olivia forget --entry` 删除 |
| `olivia forget` | 让 OLIVIA 忘掉：一条记录、全部聊天记录、一个小练习的方法偏好、锦囊与方法偏好、安全计划，或者全部数据（之后从第一次设置重新开始）。也可以直接用 `--entry 2`（序号见 `olivia memory`）、`--method 1`（序号见 `olivia memory` 的“方法偏好”，重置后这个小练习按一开始的样子推荐，锦囊和别的小练习不变）、`--ledger`、`--kit`、`--safety-plan`、`--all`。删除一条记录前会先显示是哪一条；每次删除前都要输入「确认」或「确定」（输入别的就取消，并说明什么都没删），加 `--yes` 可以跳过。删除时会销毁加密用的钥匙，留下的文件副本也再也打不开 |
| `olivia privacy` | 隐私说明：OLIVIA 在这台电脑上存了什么、存在哪个目录、哪些始终加密、哪些从不保存，以及怎么查看（`olivia memory`）和删除（`olivia health`、`olivia forget`）。运行时全程不联网 |
| `olivia resources` | 查看所在地区的求助电话（还没设置时显示全球通用的资源）。最后一行写明资料来源：随程序附带，或者签名已验证的更新包及其整理日期。不需要钥匙串：只加密健康信息时照常显示当地电话；整份设置加密又打不开、或者设置文件损坏时，先显示全球通用的资源，再说明原因（退出码 1）。随程序附带的资料没通过校验时，只显示写在程序里的常用紧急电话和 findahelpline.com，并建议重新安装 |
| `olivia settings` | 设置开关。① 系统提醒（默认关闭）：打开前会说明要在系统里装一个什么样的定时任务，并再问一次；关闭或 `olivia forget --all` 会把它删掉。② 保存方式：只加密健康信息（默认），或者把整份设置（称呼、地区、话题等）都加密；改之前会说明会怎样并再问一次，电脑没有可用的系统钥匙串时不能改成全部加密 |
| `olivia doctor` | 检查这台电脑上的运行环境，每项一行，用 ✓（正常）、!（提醒）、✗（有问题）标出：版本、数据目录和它的权限、系统钥匙串在不在、是否完成了第一次设置、各份加密保存的数据能不能打开、本机模型和随程序附带的热线资料是否通过校验（热线资料整理超过 90 天会提醒）、热线更新包是否在用、系统提醒是否已安装。全程只读、不联网，不改动任何文件，不读取钥匙串里的条目，也不解密任何数据，所以只检查文件和钥匙是否齐全、完好。输出不含称呼、话题、健康信息、安全计划或聊天内容，可以直接贴给我们。有 ✗ 时退出码为 `1` |
| `olivia chat --inspect` | 每一轮多显示一个内部状态面板，只有编号、等级和数值，不含你说的话，也不含回复原文。测试和反馈问题时有用 |
| `olivia chat --rules` | 危机筛查只用规则，不参考本机模型。以前的 `olivia chat --model` 仍然可以用，效果和直接 `olivia chat` 一样；两个不能同时给 |
| `olivia --help` | 查看全部命令 |

### 退出码

每个命令结束时的退出码遵循同一个约定，方便脚本判断：

| 退出码 | 含义 |
| --- | --- |
| `0` | 完成了要做的事（包括只是显示信息，或在输入结束时安静地退出；聊天中按 Ctrl-C 与输入结束相同） |
| `1` | 什么也没做：还没有完成第一次设置（`olivia chat` 在设置完成前结束也算），这台电脑上是未满 18 岁的记录，保存的数据现在读不出来、钥匙串打不开（这时 `olivia chat` 和 `olivia resources` 仍会先显示求助电话），另一个 OLIVIA 正在运行，或者出了意料之外的问题（这时只说一句话并建议运行 `olivia doctor`，不显示程序内部的报错）；`olivia doctor` 发现了 ✗ 项 |
| `2` | 命令写错了：参数不对，或者给的值认不出来（例如未知的地区、时区或陪伴方式；`olivia forget --entry`、`--method` 或 `olivia memory --edit` 给的序号不存在，或者 `--edit` 指向的不是你让它记住的话） |

不需要先设置就能用的命令：`olivia resources`、`olivia privacy`、`olivia doctor`、`olivia --help`、`olivia --version`，以及用来清理残留数据的 `olivia forget --all`。

### 同时打开两个 OLIVIA

同一个数据目录同一时间只让一个 OLIVIA 写入，免得两边互相覆盖、写坏加密数据。会写数据的命令——`olivia chat`、`health`、`safety-plan`、`settings`、`profile`、`journal`、`forget`、`memory --edit`，以及要修改时的 `persona` 和 `region`——发现另一个 OLIVIA 正在运行时，什么都不改，提示先关掉它，退出码为 `1`（系统提醒的定时检查则安静地跳过这一次）。只读的命令不受影响，随时可以用：`olivia resources`、`olivia privacy`、`olivia doctor`、`olivia memory`、`olivia stats`，以及只查看时的 `persona`、`region`。程序退出（包括意外中断）时这个限制自动解除。

## 数据存在哪里

OLIVIA 保存的东西都在下面这个目录里：设置文件 `profile.json`（你的称呼、年龄确认、国家/地区和时区、第一次设置时的选择；健康信息加密保存）和它的几份自动备份；以及只在有系统钥匙串时才保存、并且始终加密的：每次聊天的小结和你让它记住的话（`ledger/`）、锦囊与方法偏好（`state.bin`）、危机后的关心提醒（`care.bin`）、安全计划（`safety_plan.bin`），加密用的钥匙在 `keys/` 和系统钥匙串里。聊天原文和程序内部的分析结果不会写进文件。用 `olivia memory` 可以查看，用 `olivia forget` 可以删除。

默认位置：

- macOS：`~/Library/Application Support/olivia/`
- Linux：`~/.local/share/olivia/`
- Windows：`%LOCALAPPDATA%\olivia\`

设置环境变量 `OLIVIA_HOME` 可以换一个目录。

数据出问题时：设置文件坏了，会从自动备份恢复，并说一次恢复到了什么时候的版本，请用 `olivia health` 和 `olivia profile` 检查；加密用的钥匙坏了或不在了，不会悄悄退回更早的备份（这时会先显示求助电话，并说明可以用 `olivia forget --all` 从头开始）。文件被换成文件夹、或没有读取权限时，什么都不改，并建议运行 `olivia doctor`。`olivia forget --all` 中途被打断时，下次运行任何命令都会提示再运行一次 `olivia forget --all` 把它做完。

求助电话的更新包：维护者发布新的热线资料时，会同时给出 `hotlines.yaml` 和签名文件 `hotlines.yaml.sig`。把这两个文件放进上面目录里的 `resources/` 文件夹，`olivia chat` 和 `olivia resources` 就会改用它；签名验证不通过、缺少签名文件、内容格式不对、缺少随程序附带资料里的地区或紧急电话，或者它不比随程序附带的资料新时，仍然用随程序附带的资料，`olivia resources` 的最后一行会说明原因。删掉这个文件夹即恢复随程序附带的资料。

想清除全部本地数据，请运行 `olivia forget --all`：它会连同系统钥匙串里的那把钥匙一起删掉（只删除目录的话，钥匙还会留在钥匙串里）。这一次用不了系统钥匙串时（例如远程登录的终端），它照样删掉数据文件，并说明钥匙串里那把钥匙还没删，等能用钥匙串时再运行一次。

安装和更新时需要联网下载程序；运行时不联网：没有账号，没有使用统计，也不会自动检查更新。

## 反馈问题

请在 <https://github.com/Olivia295/OLIVIA/issues> 提交，写上：

- `olivia --version` 的输出和你的操作系统
- `olivia doctor` 的输出（不含你的个人信息）
- 你做了什么，看到了什么，原本希望看到什么
- 如果和某一轮回复有关，可以附上 `olivia chat --inspect` 的面板

这个仓库是公开的，请不要贴真实的聊天内容，也不要写任何能认出你或别人的信息。

## 开发

```bash
pip install -e '.[dev]'
bash scripts/check.sh
```

两个维护用的脚本：

- `python scripts/eval_crisis.py 文件.csv [--mode rules|model|both] [--show-ids]`：把一份标注好的 CSV（`id,text,level[,category]`）逐句交给产品的危机筛查（规则模式与模型模式），打印混淆矩阵、L2+L3 召回、L0 误报率和按类别的漏报与误报。从不打印原句；`--show-ids` 只额外列出出错样本的 id。
- `python scripts/check_hotline_freshness.py`：热线数据里任何条目的核验日期超过 90 天就以非零状态退出；GitHub Actions 每季度自动运行一次（`.github/workflows/hotline-freshness.yml`），负责人和复核步骤见 `docs/resources/hotline-sources.md`。
