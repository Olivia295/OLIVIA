## 与 PRD/SDD 的出入

1. **CN 12356 时段**（PRD GEO-02 / SDD §8.3）：“每日不少于 18 小时”与国家卫健委通知一致。但部分省份确实不是 24 小时（湖北为 8:00–次日 2:00），所以深夜时 12356 可能无人接听，L3 卡片必须同时给出 110/120，这一点 PRD 已要求。
2. **CN 属地心理热线**（PRD GEO-01/02、SDD §8.3“城市热线 → 省级 → 12356”）：各省旧热线已全部并入 12356，没有可以单独展示的省级或城市号码。所谓“属地匹配”实际上由 12356 按来电所在地自动路由。部分省份支持“区号 + 12356”拨打其他城市的线路。建议把三级路由简化为“大陆一律 12356”，`adcode` 暂不使用。
3. **CN 12355**：PRD GEO-02 未列 12355，只在 GEO-03 里出现。本数据把它列为仅限未成年人的 L2 青少年线，各地接听时段不统一。
4. **HK 生命热线**：PRD GEO-04 写“生命热线”但没有号码；SDD §8.3 写 `2389 2222`，那是“香港撒玛利亚防止自杀会”的号码，不是“生命热线”。生命热线（Suicide Prevention Services）的号码是 `2382 0000`。两者都已核实并收录。
5. **MO L3 号码**（PRD GEO-05 “999 / 110 / 112”）：澳门政府确认 110 和 112 在境内都会自动接驳到 999，所以三个号码都可以用，实际上是同一条热线。SDD §8.3 只写了 999，两者并不矛盾。另外，明爱生命热线 `2852 5222` 是中文线，外语线是 `2852 5777`。
6. **TW**：与 PRD GEO-06 一致。另外，1980 张老师不是 24 小时，只放在 L2。
7. **US/CA 文本线**（PRD GEO-07 写“北美 988 / 741741”）：741741（Crisis Text Line，发送 HOME）只适用于**美国**。加拿大的官方短信渠道是直接发短信到 **988**（2023-11-30 上线，英法双语）；加拿大政府另列 Kids Help Phone（发送 CONNECT 至 686868，面向 5–29 岁）。美国 988 同样支持短信。加拿大不应展示 741741。
8. **GB**：PRD 写“UK”，数据里的地区代码是 `GB`。NHS 111 心理健康选项只在英格兰与威尔士确认，苏格兰与北爱尔兰未核验。SHOUT 85258 已核验收录，PRD 未列。
9. **AU**：PRD 只列了 Lifeline 13 11 14。本数据另外收录了短信线 0477 13 11 14 和 Beyond Blue（均为 24/7）。另外，澳大利亚手机拨 112 也会转接到 000，而 000 不能用短信联系。
10. **ZZ 112**：欧盟委员会确认 112 在全球 GSM 网络上可拨，但并非所有国家或网络都支持，所以数据备注写明优先拨打当地紧急号码或前往最近的急诊。
11. **R8 与港澳台 110 冲突**（PRD GEO-03 对比 GEO-05/06）：GEO-03 规定非大陆地区禁止出现 110，但 110 本身就是澳门（自动接驳 999）和台湾（警察报案）的官方本地号码，GEO-05/06 也列了 110。本数据在 MO、TW 下保留了 110。R8 的检查应改为“只按 CN 条目的 id 或来源隔离”，或者把规则改成“禁止 12356 / 120 / 12355，以及大陆语境下的 110”。否则测试会误删港澳台的有效号码。
12. **数据位置**：PRD GEO-08 和 SDD §8.3 写的是 `olivia/data/resources/hotlines/` 树状目录加签名包；本轮按 P2-1 计划交付单文件 `olivia/data/resources/hotlines.yaml`，与 GEO-08 的目录结构不一致，需要后续决定。
