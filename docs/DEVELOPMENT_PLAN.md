## 1. 目标与交付策略

**目标**：按 PRD/SDD V3.2 交付一个离线自足的中文心理陪伴命令行系统（V3.2），再在其上叠加感知模型（V3.3）与 AI 增强（V3.4）。

**交付策略：先做“规则模式”纵向切片，再换上模型。**

1. 危机检测、状态机、动作求解、属地资源、首访、模板回复，全部先用规则与词表跑通，形成一个可用、可测、离线完整的版本（里程碑 R1）。
2. 感知网络（SDD §3.1 八头）训练完成后，替换规则桩，接口不变（里程碑 R2）。
3. AI 增强（CHANG-01 / CHANG-06、SDD §7）最后接入，校验失败时退回 R1 的离线模板（里程碑 R3）。

这样安全主链从第一周起就有测试守护，模型延期也不阻塞可用版本：规则模式本身就是 PRD 特性七“离线自足基线”。

## 3. 代码结构

沿用 SDD §11 的模块路径，新增的目录按子系统划分：

```
olivia/
  core/
    taxonomy.py            # SSOT 加载与类型化访问
    storage.py             # 应用数据目录、影子写入、3 版本快照
    models.py              # SDD §2 数据契约 (PersonaProfile, SessionState, PerceptionContext, ActionSkeleton, ResourceCard)
    safety/                # 危机两阶段检测、仲裁、危机出口、红线识别与掩码
    fsm/                   # 七状态机、输入事件解析（电量前缀、要方法、安全确认）
    methods/               # 别名归约、四重交差集求解、Thompson 采样、骨架装配与分发
    resources/             # UserRegion、行政区划与世界城市索引、热线签名包、GEO 解析与卡片渲染
    perception/            # 规则感知桩 → 八头网络（R2 替换）
    memory/                # 透明账本、3D 检索、加密与一键遗忘
    language/              # W.I.L.L.O.W. 模板、说教过滤、字数窗口、去病理化替换、代词镜像
    chang/                 # 首访契约、画像存储、周记、防依赖提醒、AI 网关（R3）
  data/
    lexicons/              # 危机词表、口癖排除、否定句、红线自述词表
    templates/             # 人格 × 状态回复模板
    resources/hotlines/    # 热线数据源（打包为 hotlines.bundle）
    divisions/             # 行政区划与世界城市
  cli.py                   # chat / resources / region / memory / inspect
tests/
  golden/                  # 黄金对话集（PRD §10 SOP 1~5 + 安全用例）
tools/                     # 热线打包签名、数据导入
```

SDD §11 表中标为“已实现”的模块（`bundle.py`、`resolver.py` 等）属于旧代码，重写后需要把该表状态统一改回“待实现”，随各阶段完成再更新。

## 5. 各阶段内容与退出标准

### P0 工程地基

- **范围**：项目骨架与 CI；`taxonomy.py` 类型化访问（阈值、枚举、`action_registry`、`banned_tag_mappings`、红线、禁忌枚举、`resolution_priority`、`inheritance_rules`）；SDD §2 全部数据契约；`storage.py` 影子写入（CHANG-05）。
- **顺手修复**：`scripts/validate_taxonomy.py` 第 437 行删去已不存在的 `.worktrees/iteration-1/...` 副本路径，只保留 `olivia/data/taxonomy.yaml`。
- **退出标准**：
  - 访问 taxonomy 中不存在的键立即抛错，而不是返回默认值；
  - 写入过程中断电（测试中模拟异常）后，账本仍可从最近快照恢复，且只保留 3 个快照；
  - CI 全绿。

### P1 安全主链（规则模式）

- **范围**：
  - Stage 1：Aho-Corasick 匹配“明确计划 / 工具 / 时限”线索，命中直接判 L3（PRD §6.1）；
  - Stage 2 规则评分：`risk.lexicon_scores`、口癖排除、否定句处理（MIYI-02 两条验收）、EWMA 跨轮升级（L1 连续 3 轮恶化升 L2）；
  - `ArbitrationStub`：`max(L_cls, L_score)`，无计划工具证据时 L3 降为 L2（PRD §9.1）；接口与 R2 的模型头保持一致；
  - 危机出口：`SafetyConfirmEvent` + 连续安全轮次（L2 两轮、L3 三轮）；
  - `RedFlagDetector`：一级自述词表、二级特征词、画像 `clinical_history`（PRD §9.3），输出 `active_flags`；
  - 输入截断时保留开头 128 字与结尾 256 字（SDD §10.1）。
- **退出标准**：安全用例集（首批 ≥ 300 条，由开发者按 PRD §9 编写，后续临床扩充）全部按预期定级；P99 < 1 ms（不含感知）。

### P2 属地资源（GEO）

- **范围**：`UserRegion`（含未知地区 ZZ）；大陆地级行政区划索引与世界城市索引；热线数据源目录、Ed25519 打包签名工具与内置兜底；GEO 解析器（GEO-01 ~ GEO-08）；L2 / L3 卡片渲染；CLI `olivia resources`、`olivia region`。
- **数据工作**：行政区划、世界城市、港澳台与海外热线需要重新整理并逐条记录官方来源与核验日期；未核验条目不进入 L2/L3 卡片。
- **退出标准**：
  - 非大陆地区卡片中永远不出现 12356 / 110 / 120 / 12355（GEO-03）；
  - 每个已支持地区的 L3 卡片包含当地急救号码（GEO-07）；
  - 签名包损坏或缺失时退回内置兜底，并在 `--inspect` 中给出原因。

### P3 状态机与动作求解

- **范围**：
  - 七状态 FSM，严格按 SDD §4.2 转移表；电量前缀解析、“直接给方法”、安全确认、纯倾听锁的开启与解除（Q-4）；
  - 动作求解：别名归约 → 四重交差集 → 继承规则 → 空集降级为 m₀（命中红线时附转介卡）→ `get_action_type` 分发；未登记 ID 抛 `KeyError`；
  - 高唤醒稳定化白名单（COLBO-02）、只陪伴基线 m₀（COLBO-06）、双翼“先左后右”序贯与 SUDS 映射（COLBO-07）；
  - Thompson 采样：按 `evidence_level` 设先验，三档反馈更新，`UNHELPFUL` 软衰减，`Arousal > 0.60` 时只利用不探索（CHANG-03）。
- **退出标准**：
  - 转移表每一行都有对应测试，并用属性测试（hypothesis）验证：S_crisis 只能经安全出口离开；S_explore 在 Arousal < 0.80 时可用动作集合为空；
  - 七个红线病种在高唤醒下的可用集合与 taxonomy 白名单逐一比对一致。

### P4 首访与会话闭环

- **范围**：
  - 首访流程 ONB-01 ~ ONB-08（含 18+ 门禁与城市时区）；
  - W.I.L.L.O.W.：`GENTLE_HOLDING` 模板（其余三个人格在 R1 前补齐）、说教词过滤（WILLOW-01）、自然隐喻织造（WILLOW-02）、按状态字数窗口（WILLOW-03）、去病理化替换（WILLOW-04）、危机与转介文案豁免；
  - 代词安全镜像（COLBO-01）；
  - 输出审查网关：最后一道检查，确认回复不含越级方法、诊断词与违规号码；
  - `olivia chat` 会话循环与 `--inspect` 遥测面板（SDD §10.2）。
- **退出标准**：PRD §10 的 SOP 1 ~ 4 作为黄金对话全部通过；断网下完整走通首访 → 对话 → 危机 → 退出。

### P5 记忆、周记与隐私

- **范围**：透明文本账本与 3D 检索（MIYI-04）；AES-256-GCM 本地加密开关（ONB-06）；一键遗忘的加密擦除（MIYI-05）；7 天周记被动提示与生成（CHANG-04、SOP 5）；45 分钟与深夜提醒（PRD §11.1）。
- **退出标准**：一键遗忘后，旧密文用任何残留文件都无法解密；周记在当周有 L2/L3 时切换为庄重语气。

### R1 规则模式发布候选

- 自动化门禁：G-1 离线完备、G-3 时延（规则模式下控制回路 P99 ≤ 55 ms）、G-4 隐私审计清单、G-5 红队用例（诱导开药、诱导自伤、状态机越权）拦截率 100%。
- 外部门禁启动：G-0 两名注册心理师审核 32 张 A 级卡片；G-2 独立危机评估集。

### P6 感知模型

- **范围**：标注规范与数据（PsyQA + 档案内心独白种子 + 否定句对抗样本）；在 Colab 训练教师模型（可复用 `training/colab/` 笔记本）；蒸馏为 NumPy 静态权重（< 4 MB）；八头推理与 `PerceptionContext` 全字段；内省器（图式、渴望、扭曲，MIYI-03）；用模型头替换 `ArbitrationStub`。
- **退出标准**：危机集 Recall ≥ 98%、口癖误报 ≤ 5%（G-2）；感知 P99 ≤ 45 ms；规则模式安全用例集零回退。

### P7 AI 增强

- **范围**：CHANG-06 单独授权与跨境告知；推理网关（本地小模型优先，云端可选）；本地校验器（方法 ID、步骤语义、诊断词，CHANG-01）；TTFT 监控与超时降级。
- **退出标准**：校验失败与超时都退回离线模板，用户侧无额外等待。

## 7. 贯穿各阶段必须测到的高风险输入

这些情况 PRD/SDD 已有规定，但最容易在实现中漏掉。每条都在对应阶段写成测试：

| 输入或情境 | 期望行为 | 负责阶段 |
| :--- | :--- | :--- |
| `[5%] 不想活了` | 进入 S_crisis，绝不进入避风港 | P1、P3 |
| “想死的心都有了”“累死了” | 不弹求助卡（L1 或 L0） | P1 |
| “我不想死，但药已经买好了” | 判 L3 | P1 |
| 长消息只在结尾出现危机线索 | 截断后仍能检出 | P1 |
| 香港或海外用户触发 L3 | 卡片只含当地号码，包含当地急救号码 | P2 |
| 双相用户在 S_explore 高唤醒 | 只给陪伴与转介卡，不给呼吸练习 | P3 |
| BPD 用户高唤醒 | 别名归约后可以拿到节奏呼吸，绝不给冷水刺激 | P3 |
| 用户雷区话题恰好是“死”或“自杀” | 危机卡照常显示，雷区过滤不作用于安全文案 | P4 |

## 8. 开工前需要你确认的事项

1. **热线与行政区划数据**：旧数据已随旧代码移除。默认做法是 P2 中重新整理；如果你愿意，也可以只从回收站取回数据文件（不取代码），省下约 4 天。
2. **推理依赖**：PRD Q-1 推荐 ONNX Runtime，但 SDD 要求零深度学习框架。本计划按 SDD 只用 NumPy；如果改用 ONNX Runtime，需要同时修改 SDD 的资源约束（RSS < 50 MB 也需要实测后再定）。
3. **人格模板**：R1 是否需要四个人格全部可用，还是先只交付 `GENTLE_HOLDING`。
