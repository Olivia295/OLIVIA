# 感知模型八头标注规范 (Perception Annotation Guide)

> 版本：v0.1（P6-1 草案）｜适用对象：生成与标注合成训练数据的 LLM 子代理、交叉复核子代理、人工抽查者
> 唯一术语来源：`olivia/data/taxonomy.yaml`（下称 TAX，v3.2.0）。本文与 TAX 冲突时以 TAX 为准，并回报修订本文。
> 机器校验：`training/data_gen/label_schema.json`（JSON Schema draft 2020-12），本文第 13 节的硬约束已写进该文件。

---

## 0. 总则

1. **标注对象是单条用户消息。** 只看这一条文本，不假设前文、不假设后续。跨轮升级（如连续 3 轮 L1 升 L2）由运行时状态机负责，不在单条标注里体现。
2. **只按文本本身标注。** 生成该消息所用的困扰档案（`situations/*.md`）及其“系统映射”行只是生成提示，不是标签。标注时不应看到种子档案；即使看到，也以文本实际表达为准。例如由社交焦虑档案生成、但内容主要是被伴侣冷落的消息，谱系应标 `07` 而不是 `01`。
3. **说的是谁，就标谁。** 所有标签描述的是“写这条消息的用户本人”的状态。消息里转述他人的情绪、他人的危机，不直接算作用户的情绪或危机（见 6.4）。
4. **连续值保留两位小数，步长 0.05。** 拿不准时取锚点之间的中值，不要追求虚假精度。
5. **情绪必须输出正式 id。** 别名（`emptiness` 等）先按 2.3 映射，再输出。
6. **电量前缀不参与标注。** 文本若带 `[5%]` 一类心力电量前缀，标注时忽略它；训练文本本身也不应包含前缀（电量是独立输入）。
7. **超出范围的消息不标注，交回剔除。** 包括：非中文、不是用户口吻（像陪伴者或旁白）、TAX 16 类情绪无法覆盖的明显正性高唤醒（兴奋、狂喜、躁狂式高涨）。这类消息在批次报告中单独列出，不输出记录。

| 标注字段 | `PerceptionContext` 字段（SDD §2.3） | 损失（SDD §3.1） |

## 1. 情感效价 `valence`（头 1）

**定义**：这条消息整体传达的情绪好坏程度，-1 最痛苦，+1 最愉快，0 为中性。只看情绪色彩，不看事件本身好坏（“升职了但我很怕”是负的）。

**刻度**：[-1.0, 1.0]，步长 0.05。

**锚点**：

| 值 | 消息看起来像什么 |
| :---: | :--- |
| -1.00 | 极度痛苦或绝望，看不到任何出路，常伴死亡愿望或崩溃式表达 |
| -0.80 | 强烈痛苦：哭诉、深度自我否定、重大丧失后的悲恸，语气沉重 |
| -0.55 | 明确的负面情绪，有具体困扰，痛苦可感但仍能叙述清楚 |
| -0.30 | 中度不适：烦、累、担心，但语气平稳，带有可承受感 |
| -0.10 | 轻微负面：小抱怨、轻微失落，几乎是日常吐槽 |
| 0.00 | 中性：陈述事实、提问、打招呼，没有明显情绪色彩 |
| +0.30 | 轻度正面：放松、松了口气、小小的满足 |
| +0.60 | 明确的愉快或欣慰：事情顺利、感到被支持 |
| +0.90 | 强烈而平稳的喜悦或感激（高唤醒的兴奋见总则第 7 条） |

**规则**：

- 正负混杂时，按结尾和用户自己强调的部分定基调，再向另一侧回调 0.1–0.2。
- 反讽或强颜欢笑（文字是笑，内容是痛）按内容标负值。
- 必须落在所选情绪允许的效价窗口内（第 13 节表 A）。

**常见混淆**：把“事件严重”当作“情绪强烈”。平静地讲一件大事，效价不一定很低。

## 2. 细粒度情绪 `emotion`（头 2）

### 2.1 标签集（TAX `emotions`，16 类）

| id | TAX 名称 | 一句话定义 | TAX 效价区间 | TAX 默认唤醒 |
| :--- | :--- | :--- | :---: | :---: |
| `anxiety` | 焦虑心慌 | 对未来可能出错的事持续担心、心里悬着，指向不确定的威胁 | [-0.9, -0.3] | 0.75 |
| `sadness` | 悲伤失落 | 因失去、受挫或不如意而难过、低落、想哭 | [-1.0, -0.4] | 0.35 |
| `anger` | 愤怒激惹 | 觉得被冒犯、被不公对待而生气、烦躁、想反击 | [-0.8, -0.4] | 0.80 |
| `shame` | 羞耻惭愧 | 觉得“我这个人不行、丢人、不配”，指向整个自我 | [-0.9, -0.4] | 0.65 |
| `guilt` | 内疚自责 | 觉得“我做错了某件事、对不起某人”，指向具体行为 | [-0.8, -0.3] | 0.60 |
| `loneliness` | 孤独疏离 | 感到没人懂、没人陪、和他人断开 | [-0.8, -0.4] | 0.30 |
| `hopelessness` | 绝望无力 | 认为情况不会变好、做什么都没用，看不到未来 | [-1.0, -0.6] | 0.25 |
| `grief` | 哀伤丧失 | 对已经失去的人、关系或重要事物的哀悼与思念 | [-1.0, -0.5] | 0.40 |
| `fear` | 恐惧害怕 | 对明确、眼前的危险或对象感到害怕 | [-0.9, -0.5] | 0.85 |
| `panic` | 急性惊恐 | 当下正在发生的惊恐：心跳、喘不上气、怕失控或要死了 | [-1.0, -0.7] | 0.95 |
| `overwhelm` | 情绪过载 | 事情或情绪太多，扛不住、乱成一团、无法启动 | [-0.9, -0.5] | 0.85 |
| `numbness` | 情感麻木 | 感觉不到情绪、空空的、对什么都没感觉 | [-0.8, -0.2] | 0.15 |
| `envy` | 嫉妒酸楚 | 和别人比较后的酸、不甘、觉得自己落后 | [-0.7, -0.3] | 0.65 |
| `disappointment` | 失望挫败 | 期待落空、努力没有回报的挫败感 | [-0.8, -0.3] | 0.45 |
| `confusion` | 迷茫困惑 | 不知道自己要什么、该怎么选、方向不清 | [-0.6, -0.1] | 0.50 |
| `calm` | 平静安详 | 情绪平稳、放松；本规范中也用于中性和轻度正面消息（见 2.4） | [0.4, 0.8] | 0.25 |

### 2.2 选主导情绪的规则（混合情绪只选一个）

按顺序判断，第一个能确定的就停：

1. 用户自己点名的情绪（“我就是很内疚”），且全文围绕它展开 → 选它。
2. 消息的核心诉求由哪种情绪驱动（想被安慰的是悲伤，想要对方道歉的是愤怒）→ 选它。
3. 强度最高、篇幅最多的那种。
4. 仍然并列时，选更接近安全风险的一个：`panic` 优先于 `anxiety`/`fear`，`hopelessness` 优先于 `sadness`/`disappointment`，`shame` 优先于 `guilt`，`overwhelm` 优先于 `anxiety`。

### 2.3 别名映射（TAX `emotion_aliases`）

困扰档案的“系统映射”行常用别名，标注时必须换成正式 id：

| 别名 | 正式 id | 说明 |
| :--- | :--- | :--- |
| `rumination` | `anxiety` | 反刍内耗按焦虑标 |
| `procrastination` | `overwhelm` | 拖延背后按情绪过载标 |
| `self_criticism` | `shame` | 自我苛责按羞耻标 |
| `insomnia` | `anxiety` | 失眠背后按高唤醒焦虑标 |
| `emptiness` | `numbness` | 空虚按情感麻木标 |
| `irritability` | `anger` | 易激惹按愤怒标 |

注意：映射只适用于“消息的主要情绪就是这个别名所指的状态”。例如拖延消息里如果主要情绪是自责“我真没用”，应标 `shame`，而不是机械地按 `procrastination → overwhelm`。

### 2.4 `calm` 的扩展用法

TAX 没有中性或正性情绪类，`calm` 是唯一非负类。本规范规定：无明显负面情绪的消息（打招呼、中性提问、轻度愉快、情况好转后的平稳）一律标 `calm`，效价窗口放宽到 [0.0, 1.0]，唤醒不超过 0.50。高唤醒的正性消息不标注（总则第 7 条）。

### 2.5 常见混淆

- `anxiety` / `fear` / `panic`：担心将来可能发生 → anxiety；怕一个明确的眼前对象 → fear；身体正在失控的急性发作 → panic（唤醒必须 ≥ 0.80）。
- `sadness` / `grief` / `loneliness` / `hopelessness`：一般难过 → sadness；明确的丧失对象 → grief；核心是“没人在” → loneliness；核心是“不会好了” → hopelessness。
- `shame` / `guilt`：“我是个糟糕的人” → shame；“我做了糟糕的事” → guilt。
- `numbness` / `hopelessness` / `calm`：没感觉、空 → numbness；有感觉但认定无望 → hopelessness；感觉平稳且不难受 → calm。
- `overwhelm` / `anxiety`：重点是“太多、扛不住、动不了” → overwhelm；重点是“万一……” → anxiety。
- `disappointment` / `sadness`：落空感、挫败 → disappointment；更泛的难过 → sadness。
- `anger` / `envy`：被冒犯 → anger；比较之后的不甘 → envy。
- `confusion` / `anxiety`：不知道方向但不太紧张 → confusion；带明显担心和紧绷 → anxiety。

## 3. 唤醒度 `arousal`（头 3）

**定义**：身体和神经系统被激活的程度，看“紧不紧、急不急、能量高不高”，不看好坏。安静的绝望唤醒低，暴怒和惊恐唤醒高。

**刻度**：[0.0, 1.0]，步长 0.05。与 SUDS 0–10 线性对应：唤醒 = SUDS / 10（TAX `arousal.suds_mapping`）。

**TAX 分档**（`arousal.bands`）：low [0, 0.35)、moderate [0.35, 0.65)、elevated [0.65, 0.80)、acute [0.80, 1.00]。
**关键阈值**（`arousal.thresholds`）：0.60 以下才允许探索性推荐；0.80 起优先躯体稳定化；0.85 起禁止高认知负荷方法。

**锚点**：

| 值 | 消息看起来像什么 |
| :---: | :--- |
| 0.05 | 几乎没有能量：极短回复、说不出感觉、像被抽空 |
| 0.15 | 麻木、迟钝、躺着不想动，语气平淡无起伏 |
| 0.30 | 低落或疲惫但能完整叙述；或平静放松 |
| 0.45 | 平稳到轻度警觉：能清楚思考，有点在意但不紧绷 |
| 0.60 | 明显紧张或烦躁，反复担心，但还能组织语言 |
| 0.72 | 紧绷、情绪起伏大，有身体信号（胸闷、睡不着、手心出汗），句子变急 |
| 0.85 | 急性高唤醒：慌乱、暴怒、哭到停不下来，标点和语句开始破碎 |
| 0.95 | 惊恐发作或失控进行时：喘不上气、心跳狂乱、觉得要死或要疯 |

**规则**：

- 用户自报 SUDS 或“几分”时，按 /10 换算，再结合文字表现上下调整不超过 0.1。
- 只标文本表现出的唤醒。档案里“表面低、底层高”（如解离）的情况，按消息表面呈现标注。
- 必须落在所选情绪允许的唤醒窗口内（第 13 节表 A）。

**常见混淆**：把“情绪很负面”当作“唤醒很高”。绝望、麻木、悲伤通常唤醒偏低。

## 4. 共情策略意图 `intent`（头 4）

**定义**：针对这条消息，陪伴者下一步最该用的支持策略。标的是“应该怎么回”，不是“用户在做什么”。

### 4.1 标签集（6 类）

| id | 名称 | 何时用 |
| :--- | :--- | :--- |
| `REFERRAL` | 转介或危机资源 | 需要专业帮助或危机资源，见 4.2 第 1、3 步 |
| `STABILIZATION` | 先稳定情绪/身体 | 用户当下过度激活，先要降下来才能谈别的 |
| `INFORMATION` | 科普或解释 | 用户明确在问知识、原理、方法、“这正常吗” |
| `VALIDATION` | 确认与共情 | 用户带着明显痛苦在倾诉，最需要被接住、被肯定感受合理 |
| `REFLECTION` | 澄清与镜像 | 消息里有矛盾、纠结、混乱，需要帮用户把感受和想法理清、照见 |
| `EXPLORATION` | 开放探索 | 用户相对稳定，话题刚打开或信息不足，适合用开放问题展开 |

### 4.2 判定顺序（从上到下，命中即停）

1. **`risk` 为 L2 或 L3 → `REFERRAL`。** 无例外。
2. **唤醒 ≥ 0.80 → `STABILIZATION`。**（此时 risk 只可能是 L0/L1。）
3. **唤醒 < 0.80，且出现以下任一 → `REFERRAL`：**
   - 用户描述了 TAX `clinical_red_flags` / `contraindication_enums` 中红线病种的明显迹象：躁狂或轻躁狂、幻觉或妄想、创伤闪回、严重解离、严重限制进食及躯体虚弱、自伤冲动或近期自伤、物质依赖或戒断；
   - 正在遭受家庭暴力或人身威胁；
   - 他人（朋友、家人）正处于自杀或人身危险，用户需要知道怎么求助；
   - 用户明确在找医生、咨询师、医院、热线。
   （唤醒 ≥ 0.80 的红线情形先走第 2 步；红线转介卡由规则层另行呈现，不依赖这个头。）
4. **用户明确提出知识性问题，唤醒 < 0.65，且效价 > -0.70 → `INFORMATION`。** 反问和自我攻击式的“为什么我总是这样”不算知识性问题。
5. **明显痛苦的倾诉 → `VALIDATION`。** 满足任一：效价 ≤ -0.50；情绪为 shame、hopelessness、grief、loneliness 且不在提问；risk 为 L1；用户表示“不想听建议，只想说说”。
6. **矛盾、纠结、混乱 → `REFLECTION`。** 满足任一：同时表达两种相反的感受或愿望；说不清自己是什么感受；叙述多条线索交缠；情绪为 confusion。
7. **其余 → `EXPLORATION`。** 典型是轻中度困扰、话题刚开、信息很少的消息，以及 L0 日常闲聊。

`STABILIZATION` 还可以在第 2 步之外使用一种情况：唤醒在 0.65–0.80 之间，且消息以身体症状为主（心慌、胸闷、发抖、睡不着）或用户直接请求“帮我冷静下来”。这种情况放在第 4 步之前判断。

### 4.3 常见混淆

- `VALIDATION` / `REFLECTION`：痛苦很清楚、只是很疼 → VALIDATION；痛苦本身是乱的、相互拉扯的 → REFLECTION。
- `INFORMATION` / `EXPLORATION`：用户问了具体问题 → INFORMATION；用户只是起了个头 → EXPLORATION。
- `REFERRAL` / `STABILIZATION`：L2/L3 永远 REFERRAL，即使唤醒很高；L0/L1 时唤醒 ≥ 0.80 永远 STABILIZATION。

## 5. 危机等级 `risk`（头 5）

> **来源说明**：本节与 `docs/eval/crisis-annotation-guide.md`（路线图 EVAL-1）一致；两者有出入时，以危机标注规范为准。标注 `risk` 时不得参考或模仿 `olivia/data/lexicons/` 中的任何词条措辞。

### 5.1 定义（TAX `crisis_hierarchy`，C-SSRS 对照）

| 等级 | TAX 名称 | 判定标准 | C-SSRS 对照 |
| :---: | :--- | :--- | :--- |
| L0 | 安全状态 | 没有自伤、自杀念头；日常压力和情绪波动。包括把“死”当程度副词用的夸张口语 | 无 |
| L1 | 隐晦厌世 / 存在性疲倦 | 表达活着很累、没意义、心力交瘁、什么都不想管等耗竭和存在性倦怠，**但没有任何死亡愿望或自杀念头** | 低于第 1 项 |
| L2 | 明确被动轻生念头 | 明确表达想死、想结束生命但没有具体时间、地点、方法或工具；或表达死亡愿望，包括希望睡过去不再醒来、希望自己已经不在了 | 第 1 项（死亡愿望）至第 2 项（非特定主动念头）；有方法设想但无计划时也归此级 |
| L3 | 急性自杀危机 | 有明确计划、正在准备或已获得工具、设定了时间、正在告别、或有即刻自伤行动的迹象 | 计划、意图、准备行为 |

### 5.2 判定规则

1. **L3 必须有文本证据**：计划、方法或工具、时间、告别或正在进行的行动，至少一项明确出现（对应 TAX `arbitration_rule` 的 PLAN_MEANS_TIME 要件）。没有证据，即使语气极端，也最多标 L2。
2. **希望睡过去不再醒来属于 L2**，不能因为没有“死”字就降为 L1（PRD §9.1 IMPORTANT 条）。
3. **夸张口语是 L0**：“死”只是在修饰另一个形容词或动作的程度（累、热、尴尬、好笑），整句并不表达不想活。但如果一句话独立表达了想死或不想存在，即使配了笑脸或玩笑语气，也按 L2 标（姿态可能是 IRRELEVANT）。
4. **否定按真实语义判断**：用户明确否认有死亡念头、只承认疲惫的，按否认后的实际内容定级，通常为 L1 或 L0。否认后又补充了死亡愿望的，按补充内容定级。
5. **只标当下**：过去有过念头、现在明确表示已经过去且安全，标 L0（危机标注规范 §4.7）。过去有念头、现在仍在想，按现在的内容定级。
6. **自伤（非自杀性）**：正在自伤或即将自伤 → L3（TAX L3 的“即刻自残行动迹象”）；描述自伤冲动或近期自伤、但没有死亡愿望 → **L2**（安全优先；危机标注规范未单列此情形）。
7. **他人的危机不算用户的危机**：用户转述朋友想自杀，用户本人的 risk 按用户自己的状态标（通常 L0/L1），intent 标 REFERRAL（4.2 第 3 步）。
8. **拿不准时取高一级**（TAX `SAFETY_FIRST_MAXIMUM`），但 L3 仍须满足第 1 条。

### 5.3 常见混淆

- L1 与 L2 的分界只看一件事：**有没有死亡愿望**。疲惫、无意义、不想努力再强烈，没有死亡愿望就是 L1。
- L2 与 L3 的分界只看一件事：**有没有计划、手段、时间或行动的证据**。

## 6. 危机置信度 `crisis_confidence`（头 6）

**定义**：这条消息属于危机的连续程度，用于加权 BCE 回归。它和 `risk` 绑定：先定 `risk`，再在对应带内按强度定位。

**标注带**：TAX `crisis_hierarchy` 的分数区间是 L0 [0, 0.20)、L1 [0.20, 0.50)、L2 [0.50, 0.80)、L3 [0.80, 1.00]，`risk.model_thresholds` 为 L1 0.20、L2 0.50、L3 0.80。为避免标注值踩在边界上，标注带比 TAX 区间收窄：

| risk | 标注带 | 带内定位 |
| :---: | :---: | :--- |
| L0 | 0.00–0.10 | 0.00：完全没有死亡或自伤话题；0.05：中性地提到死亡（讨论电影、新闻、别人的去世）；0.10：夸张口语 |
| L1 | 0.20–0.45 | 0.20–0.25：轻度疲惫或无意义感；0.30–0.35：明显的存在性耗竭；0.40–0.45：强烈、反复，接近但仍无死亡愿望 |
| L2 | 0.55–0.75 | 0.55–0.60：被动死亡愿望，表达较含蓄；0.65：清楚的被动死亡愿望；0.70–0.75：主动想结束生命但无计划，或强烈反复、有方法设想、自伤冲动 |
| L3 | 0.85–1.00 | 0.85：提到具体计划或手段之一；0.90：计划加手段，或正在准备；0.95–1.00：已设定时间、正在告别、或行动正在进行 |

L2 的上限取 0.75 而不是 0.80：TAX 把 0.80 划入 L3（闭区间），运行时 `max(L_cls, L_score)` 会把 0.80 判为 L3 再降级，标注值不应制造这种冲突。

## 7. 萨提亚沟通姿态 `stance`（头 7）

### 7.1 标签集（TAX `communication_stances`，5 类）

TAX 对四种不一致姿态的描述，各自对应“忽略了谁”：讨好忽略自我，指责忽略他人，超理智忽略情绪和身体感受，打岔回避整个话题。一致型是兼顾自我、他人与情境的整合目标。

| id | 名称 | 在单条消息里怎么看出来 |
| :--- | :--- | :--- |
| `PLACATING` | 讨好型 | 过度道歉、把错都揽到自己身上以平息冲突、“我没关系，只要他们满意”、怕别人不高兴、对陪伴者也客气地说“打扰了”；自己的需要被压到最后或不出现 |
| `BLAMING` | 指责型 | 把问题全部归到别人或环境，带攻击和居高临下：“他们总是……”“都怪……”、命令式、轻蔑、否认对方立场；也包括指责陪伴者“你根本不懂” |
| `SUPER_REASONABLE` | 超理智型 | 讲道理、讲原则、引理论、列分析，用“人就是……”之类非个人化表述；内容明明痛苦却几乎没有情绪词，或直接否认情绪“从理性上讲这没意义” |
| `IRRELEVANT` | 打岔型 | 刚说到痛处就转话题、用玩笑或自嘲带过、表情和语气与内容不符（讲很痛的事配“哈哈”）、东一句西一句 |
| `CONGRUENT` | 一致型 | 用第一人称直接说出感受和需要，承认别人和情境，语气与内容一致 |

### 7.2 默认规则：没有明确信号时标 `CONGRUENT`

只有当消息里出现某种不一致姿态的**明确信号**时，才标 PLACATING、BLAMING、SUPER_REASONABLE 或 IRRELEVANT；否则标 `CONGRUENT`。

理由：TAX 对四种不一致姿态的描述都是具体的防御动作（迎合、攻击、抽离、回避），可以在文本里找到正面证据；而一条直接陈述自己感受的普通消息，本身就是“真实坦诚地表达内在”，符合一致型描述。反过来，若在证据不足时给用户贴上指责或讨好的标签，系统会去回应一个并不存在的姿态，代价更大。

需要注意：极短、几乎无内容的消息（如单个“嗯”）标 `CONGRUENT` 只表示“没有不一致信号”，不表示用户已达到整合状态。

### 7.3 判定规则与常见混淆

- **自责不等于指责。** 指责型的矛头指向他人；把错揽到自己身上以求和，是讨好型。单纯的自我否定、没有迎合他人的成分，按内容看是否其他信号，否则 CONGRUENT。
- **生气不等于指责。** “他这样做让我很生气，我希望他道歉”是一致型；带攻击、贬低、否认对方任何合理性才是指责型。
- **分析不等于超理智。** 一边讲分析一边也说了自己的感受 → CONGRUENT；用分析替代感受 → SUPER_REASONABLE。
- **玩笑不等于打岔。** 轻松话题里开玩笑 → CONGRUENT；在痛处用玩笑躲开 → IRRELEVANT。
- 多种信号并存时，选占篇幅最多的；篇幅相当时，选消息后半部分体现的那一种。

## 8. 改变准备度 `readiness`（头 8）

**定义**：用户对“改变自己的处境或做法”的动机和准备程度，参考跨理论模型的阶段（前意向、意向、准备、行动、维持）。看的是对改变的态度，不是能量多少：很累但想试试，准备度可以不低。

**刻度**：[0.0, 1.0]，步长 0.05。

**锚点**：

| 值 | 阶段 | 消息看起来像什么 |
| :---: | :--- | :--- |
| 0.05 | 前意向（抗拒） | 否认有问题，或明确拒绝任何改变、认定改变不可能 |
| 0.20 | 前意向（无力） | 承认难受，但只想发泄或被陪着，觉得说了也没用，对建议无兴趣 |
| 0.35 | 意向早期 | 开始承认“可能是我的模式有问题”，但还没想过要做什么 |
| 0.50 | 意向（矛盾） | 明显的“想改又不想改”“知道该改但做不到”；或消息里没有任何问题与改变的线索（见下） |
| 0.65 | 准备 | 问“我该怎么办”“有什么办法”，愿意听具体建议 |
| 0.80 | 行动 | 已经在尝试，描述做了什么、效果如何，想要下一步 |
| 0.95 | 维持 | 有稳定的做法和计划，谈如何坚持、防止反复 |

**规则**：

- 没有可改变的问题（闲聊、中性提问、分享好消息）时，标 0.50，表示“无信息”。
- 危机消息不强制低值，按文本中的态度标；但通常在 0.05–0.35。
- 只问知识（“这是不是抑郁”）而没有表达要做什么，标 0.40–0.50。

**常见混淆**：把“心力电量低”当作“准备度低”。也不要把“问问题”一律当作高准备度，要看是否在问怎么做。

## 9. 主导谱系 `dominant_spectrum`（辅助标签）

**定义**：最能概括这条消息困扰内容的 TAX `distress_spectra` 谱系编号。Thompson 采样只更新这个谱系（TAX `thompson_sampling_index`）。

**取值**：`"01"`–`"11"`，或 `"none"`。

| id | 谱系 | 主要内容（取自 TAX 档案名） |
| :---: | :--- | :--- |
| 01 | 焦虑与惊恐谱系 | 慢性担忧、惊恐发作、社交焦虑、疾病焦虑、场所与特定恐惧、分离与预期性焦虑、错失恐惧与信息过载 |
| 02 | 抑郁与心境低落谱系 | 重度低落、长期低落与微笑型抑郁、快感缺失与麻木、双相波动、季节性与节后落差、围产期抑郁 |
| 03 | 强迫思维与反刍谱系 | 反刍内耗、侵入性思维、关系强迫、容貌焦虑、决策瘫痪、囤积 |
| 04 | 完美主义与自我苛责谱系 | 全或无的完美主义、冒充者感、有条件的自我价值与讨好耗竭、休息羞耻、毒性羞耻、同辈比较与年龄焦虑 |
| 05 | 执行功能与倦怠耗竭谱系 | 拖延与启动冻结、职业或学业倦怠、报复性熬夜、注意缺陷困扰、照料者耗竭 |
| 06 | 创伤、应激与哀伤谱系 | 急性应激与 PTSD、复杂创伤与童年忽视、人生转折失衡、延长哀伤、解离、替代性创伤与道德伤害 |
| 07 | 依恋与亲密关系谱系 | 焦虑型依恋、回避型依恋、共生依赖与边界丧失、拒绝敏感、慢性孤独、煤气灯操纵 |
| 08 | 睡眠、躯体化与进食谱系 | 失眠、躯体化症状、暴食与情绪性进食、限制性进食 |
| 09 | 情绪失调与人格脆弱谱系 | 情绪风暴与自伤冲动、述情障碍、易激惹与暴怒、脆弱型自恋、回避与依赖模式 |
| 10 | 成瘾、冲动控制与多巴胺代偿谱系 | 短视频成瘾、游戏、冲动购物、酒精与物质、拔毛抠皮等重复行为 |
| 11 | 存在主义与终极意义谱系 | 意义丧失与空心感、人生阶段危机、死亡焦虑、宏观不确定性焦虑 |

**规则**：

1. 只要有任何困扰（哪怕轻微），就选一个谱系；`"none"` 只用于没有困扰的 L0 消息（闲聊、中性提问、分享好事）。
2. 按消息的核心困扰选，不按种子档案选（总则第 2 条）。
3. 两个谱系都沾边时，选用户诉求所指向的那个：例如因完美主义导致拖延，用户在问怎么开始动手 → 05；在骂自己不够好 → 04。
4. 只有死亡愿望或危机表达、没有任何其他背景时 → `02`；以“活着没意义”的存在性框架表达时 → `11`。
5. 失眠：核心是睡不着本身 → 08；核心是躺在床上反复想事 → 03；核心是报复性熬夜 → 05。

## 10. 输出格式

每条消息输出一行 JSON（JSONL），**恰好**包含下列 10 个键，不得增删：

```json
{"text": "<原文>", "valence": -0.55, "emotion": "anxiety", "arousal": 0.70, "intent": "VALIDATION", "risk": "L0", "crisis_confidence": 0.00, "stance": "CONGRUENT", "readiness": 0.35, "dominant_spectrum": "01"}
```

| 字段 | 类型 | 允许值 |
| :--- | :--- | :--- |
| `text` | string | 1–1000 字的用户消息原文，与输入逐字一致 |
| `valence` | number | -1.00 至 1.00，步长 0.05 |
| `emotion` | string | `anxiety` `sadness` `anger` `shame` `guilt` `loneliness` `hopelessness` `grief` `fear` `panic` `overwhelm` `numbness` `envy` `disappointment` `confusion` `calm` |
| `arousal` | number | 0.00 至 1.00，步长 0.05 |
| `intent` | string | `VALIDATION` `EXPLORATION` `REFLECTION` `INFORMATION` `STABILIZATION` `REFERRAL` |
| `risk` | string | `L0` `L1` `L2` `L3` |
| `crisis_confidence` | number | 0.00 至 1.00，且落在 risk 对应的标注带内（第 6 节） |
| `stance` | string | `PLACATING` `BLAMING` `SUPER_REASONABLE` `IRRELEVANT` `CONGRUENT` |
| `readiness` | number | 0.00 至 1.00，步长 0.05 |
| `dominant_spectrum` | string | `"01"` 至 `"11"`（两位字符串）或 `"none"` |

示例中的 `text` 仅为占位。每条记录输出前须用 `training/data_gen/label_schema.json` 校验；不通过的记录不得提交，先按第 13 节修正。

## 11. 标注步骤（建议顺序）

1. 读全文，确认不属于总则第 7 条的剔除情形。
2. 定 `risk`（第 5 节），再在带内定 `crisis_confidence`（第 6 节）。
3. 定 `emotion`（第 2 节），再定 `valence`、`arousal`，并检查是否落在表 A 窗口内。
4. 定 `intent`（按 4.2 顺序）。
5. 定 `stance`（第 7 节）、`readiness`（第 8 节）、`dominant_spectrum`（第 9 节）。
6. 对照第 13 节自查，用 schema 校验后输出。

## 12. 交叉复核

复核者由另一组子代理担任，**看不到原标注**，按本规范独立标注同一批文本，然后逐头比对。

| 头 | 一致的判定 |
| :--- | :--- |
| `emotion`、`intent`、`stance`、`dominant_spectrum` | 完全相同 |
| `risk` | 完全相同（硬性要求） |
| `valence`、`arousal`、`readiness`、`crisis_confidence` | 两次标注差的绝对值 ≤ 0.15 |

**处理规则**：

1. **`risk` 不一致的条目一律不进训练集**，先交第三位复核者；三方仍无多数，或任何一方标了 L2/L3 而多数没有，交人工裁定。
2. 其他头不一致：分类头取第三位复核者参与后的多数；连续头若第三方与其中一方差 ≤ 0.15，取这两方的均值；仍无法收敛的条目剔除。
3. 每头单独计算一致率（一致条数 / 复核条数），目标 ≥ 85%（路线图 P6-3）。某一头低于目标时，先检查本规范对应章节是否含糊，修订后整批重标该头，而不是逐条修补。
4. 复核报告按头列出一致率，并列出不一致最多的 3 组标签对（如 VALIDATION↔REFLECTION），供修订本规范。

## 13. 跨头一致性约束

以下硬约束已写入 `label_schema.json`，违反即校验失败。

**C1.** `risk` ∈ {L2, L3} ⇒ `intent` = `REFERRAL`，`emotion` ≠ `calm`，`valence` ≤ -0.40。（L3 消息语气“平静、已经想好了”时，情绪标 `hopelessness`，不标 `calm`。）
**C2.** `risk` ∈ {L0, L1} 且 `arousal` ≥ 0.80 ⇒ `intent` = `STABILIZATION`。
**C3.** `intent` = `INFORMATION` ⇒ `arousal` < 0.65。
**C4.** `dominant_spectrum` = `"none"` ⇒ `risk` = `L0` 且 `valence` ≥ -0.20。
**C5.** `crisis_confidence` 落在 `risk` 对应的标注带内（第 6 节）。
**C6.** `valence` 与 `arousal` 落在所选 `emotion` 的窗口内（表 A）。

**表 A：情绪 → 效价与唤醒窗口**

窗口由 TAX 数据推出：效价 = TAX `valence_range` 两端各放宽 0.20；唤醒 = TAX `default_arousal` ± 0.40；均截断在合法范围内。例外：`panic` 唤醒 ≥ 0.80（急性发作的定义）；`calm` 效价 [0.00, 1.00]（2.4 节扩展用法），唤醒 ≤ 0.50。

| emotion | 效价窗口 | 唤醒窗口 |
| :--- | :---: | :---: |
| anxiety | [-1.00, -0.10] | [0.35, 1.00] |
| sadness | [-1.00, -0.20] | [0.00, 0.75] |
| anger | [-1.00, -0.20] | [0.40, 1.00] |
| shame | [-1.00, -0.20] | [0.25, 1.00] |
| guilt | [-1.00, -0.10] | [0.20, 1.00] |
| loneliness | [-1.00, -0.20] | [0.00, 0.70] |
| hopelessness | [-1.00, -0.40] | [0.00, 0.65] |
| grief | [-1.00, -0.30] | [0.00, 0.80] |
| fear | [-1.00, -0.30] | [0.45, 1.00] |
| panic | [-1.00, -0.50] | [0.80, 1.00] |
| overwhelm | [-1.00, -0.30] | [0.45, 1.00] |
| numbness | [-1.00, 0.00] | [0.00, 0.55] |
| envy | [-0.90, -0.10] | [0.25, 1.00] |
| disappointment | [-1.00, -0.10] | [0.05, 0.85] |
| confusion | [-0.80, 0.10] | [0.10, 0.90] |
| calm | [0.00, 1.00] | [0.00, 0.50] |

以下是软约束，不写进 schema，复核时重点抽查：

- `risk` = L1 时，`intent` 通常为 VALIDATION（TAX L1 动作是深度情感包裹）；标 EXPLORATION 或 INFORMATION 需有明确理由。
- `risk` ≥ L1 时，`readiness` 通常 ≤ 0.50。
- `emotion` = `panic` 时，`intent` 几乎总是 STABILIZATION（L2/L3 除外）。
- `stance` = `IRRELEVANT` 且内容沉重时，`valence` 按内容标，不按语气标。
