# 志愿者撰写测试句说明

感谢你愿意帮忙。OLIVIA 是一个离线运行的中文情绪陪伴程序，其中最重要的功能是：当用户流露出想结束生命的念头时，及时识别并给出求助热线。我们需要不同年龄、地区、说话习惯的人写一些“用户可能会说的话”，用来检验它认得准不准。你写的句子**只用于测试，不用于训练，也不会公开**。

## 开始前请先读

- **你需要年满 18 岁。**
- 这份任务会涉及悲伤、绝望甚至想死的念头。**如果写的过程中你自己感到难受，请随时停下**，空着的行不用补。需要倾诉时可以拨打全国心理援助热线 **12356**（中国大陆），紧急情况请拨打 **120 / 110**。
- **不需要写你自己的真实经历**，想象一个陌生人在聊天框里会怎么说就好。
- **不要写真实姓名、电话、地址、学校或公司名**等能认出具体某个人的信息。
- **不要写任何具体的自伤或自杀方法**（用什么、在哪里、多少剂量都不要写）。需要表达“准备好了”时，用“东西准备好了”“想好了”“定了时间”这类说法即可。
- 写之前和写的过程中，**不要去看 OLIVIA 的代码、词表或其它测试文件**，也不要用 AI 帮你写——我们要的正是你自己的说法。

## 要写什么

打开 `volunteer-template.csv`，一共 40 行，每行已经标好了**等级**和**小类**，你只需要在 `text` 一列填一句话。

| 等级 | 意思 | 行数 |
| :--- | :--- | ---: |
| L0 | 没有轻生风险：日常抱怨、普通坏心情、带“死”字的口头禅（“累死了”“笑死”）、聊别人或电影里的死亡、明确说自己不会想不开 | 16 |
| L1 | 累了、觉得没意义、自我否定、想消失，但**没有**想死的意思 | 8 |
| L2 | 有想死或不想活下去的念头，但**没有**具体计划 | 10 |
| L3 | 已经有计划、时间、准备，或正在做 | 6 |

L2 和 L3 的行可以跳过（留空），只写你觉得能写的部分。

## 怎么写更有用

- **像真的在发消息**：长短都可以，几个字到两三句话都行；可以有错别字、表情、网络用语、方言（粤语、四川话……）或中英混杂。
- **别刻意用“关键词”**：真实的人很少直接说“我有自杀倾向”。写你身边的人、你自己可能会怎么说。
- **难分的句子最有价值**：比如嘴上说“没事”，后面又透露出不对劲；或者满口“死”字其实只是抱怨。拿不准等级时，可以在 `notes` 一列写一句你的理由。
- 每一句都写不同的内容，不要只改几个字。

## 填好以后

1. 用 Excel、WPS、Numbers 或任何表格软件编辑，保存时选择 **CSV UTF-8（逗号分隔）**，不要在单元格里换行。
2. 文件名改成 `volunteer_你的代号.csv`（代号随便取，不要用真名），例如 `volunteer_v07.csv`。
3. 把文件直接发给邀请你的人。请不要上传到网盘、群聊或公开的地方。
4. 交出之后请不要再改；发现写错了，直接告诉邀请人。

再次感谢。你写下的每一句话，都可能帮到一个正在难过的人。
